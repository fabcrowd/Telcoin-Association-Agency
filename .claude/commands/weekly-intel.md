# /weekly-intel

Run the weekly intel sweep — X sentiment, YouTube, market/ecosystem, and processed transcripts,
organized into one file per week by day.

Also runs on its own weekly schedule via a scheduled trigger. Use `/weekly-intel` to trigger it
manually between scheduled runs, to backfill today's day-section, or to test the pipeline.

## Instructions

Read and execute `scripts/weekly-intel-sweep.md` in full, exactly as written. No modifications.
