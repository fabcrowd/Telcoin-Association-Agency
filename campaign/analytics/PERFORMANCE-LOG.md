## How to Update This File

1. Go to analytics.x.com (logged in as @telcoinTAO)
2. Export **Account Overview** (by day) and/or **Tweet activity** (by Tweet)
3. Run `python3 scripts/x-analytics-import.py path/to/export.csv`
4. Re-run regenerates `campaign/analytics/account-overview/daily.json` and refreshes this log
5. For per-post rows (Type/Topic/Link clicks), also export **by Tweet** from the Posts tab

**This import is Account Overview (day totals).** Per-post Type/Topic/Link-click columns
stay blank until a Tweet-activity CSV is provided — day-level impressions/engagements
below are measured and complete.
