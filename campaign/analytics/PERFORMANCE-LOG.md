## How to Update This File

1. Go to analytics.twitter.com
2. Select date range (last 7 days)
3. Export or manually copy metrics for each post
4. Paste into the Weekly Log table below (newest week at top)
5. Update Top Performers and Patterns sections
6. Agents will read this at next session start

**Metrics to capture per post:**
- Date published
- Post type (governance / education / milestone / community)
- Topic (short label)
- Impressions
- Engagements (total interactions)
- Engagement rate (%)
- Link clicks (if applicable)
- Profile visits driven
- Replies / Retweets / Likes (if available)
