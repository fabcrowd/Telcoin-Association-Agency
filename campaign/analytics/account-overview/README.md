# @telcoinTAO Account Overview store

Measured day-level totals from analytics.x.com **Account Overview** CSV exports.

- `daily.json` — compiled series (schema v1), regenerated by
  `python3 scripts/x-analytics-import.py path/to/account_overview.csv`
- Source CSVs are archived under `campaign/analytics/x-exports/`

This is **measured**-tier data for an account we control. It does **not** include
per-post permalinks — those require a Tweet-activity (Export by Tweet) CSV, which
fills `own_account.posts[]` on `campaign/analytics/sentiment/YYYY-MM-DD.json`.

The dashboard (`campaign/analytics/sentiment/dashboard.html`) plots this series
independently of the community-listening "Collecting · day N/14" gate.
