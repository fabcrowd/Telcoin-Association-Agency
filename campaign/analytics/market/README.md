# $TEL market data store

`tel-price-history.json` — daily price/market-cap/volume series for $TEL, from
CoinGecko. Regenerated by `python3 scripts/tel-price-history.py`.

**Why this exists**: real historical community sentiment/mentions cannot be
recovered for free (WebSearch has no time machine — see
`scripts/sentiment-scraper.md` Step 0b, which confirmed this empirically with a
zero-result backfill attempt). $TEL's market history genuinely exists back to
token listing and CoinGecko publishes it for free — the best available
"historical $TEL data" without spending anything (standing $0 budget, see
`campaign/AGENCY-MEMORY.md`).

**Two-tier fetch, on purpose**:
- The file's deep history (2018-02-01 onward) was seeded **once** (2026-08-22)
  via the CoinGecko MCP available inside Claude sessions, which has broader
  access than an unauthenticated script.
- Routine refreshes run the plain public CoinGecko API (no key, no signup),
  which caps at the trailing 365 days — `scripts/tel-price-history.py` **merges**
  by date rather than overwriting, so a routine re-run never destroys the seeded
  depth.

**Listen-only.** Per `campaign/analytics/NARRATIVE-TAXONOMY.json`, `price` is
`publishable: false` — @telcoinTAO never comments on price action or market cap.
This data is dashboard/internal context only, paired against the sentiment
series to spot correlation or divergence — never a source for a public post.
